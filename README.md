# web-vuln-lab

웹 취약점을 직접 구현하고, 터뜨리고, 막아보는 실습 저장소.

## 왜 만들었나

취약점 설명을 읽는 것과 직접 재현해보는 것은 다르다.
웹 해킹 로드맵을 따라가면서 각 취약점을

1. 의도적으로 심고
2. PoC로 재현하고
3. 완화 커밋으로 막는다

이 세 단계를 하나의 커밋 흐름으로 남기는 것이 목적이다.

## 진행 상황

드림핵 「웹 해킹 기초」 로드맵 8유닛과 1:1로 맞춘다 (2026-09 기준).

| # | 취약점 | 구현 | PoC | 완화 |

| 1 | XSS | ⬜ | ⬜ | ⬜ |
| 2 | CSRF | ⬜ | ⬜ | ⬜ |
| 3 | SSRF | ⬜ | ⬜ | ⬜ |
| 4 | Access Control | ⬜ | ⬜ | ⬜ |

## 디렉터리 구조

```
vuln/<name>/
├── app/        취약한 구현
├── poc/        재현 스크립트
├── fix/        완화 적용 후 구현
└── README.md   원리 · 재현 절차 · 완화 근거
```
